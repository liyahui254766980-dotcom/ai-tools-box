1️⃣ AI写作接单

做什么：帮客户写公众号文章、SEO文章、产品文案、社交媒体内容等。

工具：ChatGPT / Claude + 自己的润色修改

接单渠道：猪八戒、闲鱼、小红书、知识星球、公众号投稿

操作建议：不要直接把AI生成的内容丢给客户。用AI生成初稿，然后人工润色30%以上（调整语气、补充案例、优化逻辑）。价格建议：公众号文章 300-800元/篇，SEO文章 200-500元/篇。

2️⃣ AI设计接单

做什么：Logo设计、海报设计、社交媒体配图、产品包装设计

工具：Midjourney（图像生成）+ Canva（排版修改）+ AI抠图工具

接单渠道：猪八戒、Fiverr、闲鱼、小红书

操作建议：用AI生成概念图，然后在Canva里排版加文字。Logo设计要多次迭代，给客户3-5个方案选择。价格建议：Logo 200-1000元，海报 150-500元。

3️⃣ AI短视频制作

做什么：知识科普、AI讲故事、产品评测、情感语录等短视频

工具：ChatGPT（脚本）+ 剪映（剪辑/配音）+ Midjourney/DALL-E（配图）+ 可灵/Sora（AI视频）

变现方式：抖音/快手流量分成、接广告、带货、知识付费

操作建议：选一个垂直领域（AI工具推荐、历史故事、英语教学等），保持日更或隔日更。前期靠AI工具快速产出，积累粉丝后接广告变现。

4️⃣ AI配音 / 有声书

做什么：帮自媒体人做视频配音，或者制作有声书上传到喜马拉雅/蜻蜓FM

工具：讯飞配音（中文）/ ElevenLabs（英文）/ 剪映

操作建议：有声书是最被低估的AI副业。用AI把畅销书/网络小说转成音频，上传到有声平台。按播放量分成，一本好的有声书可以持续带来收入。

5️⃣ AI编程接单

做什么：网站建设、小程序开发、爬虫脚本、自动化工具

工具：Cursor / Copilot + ChatGPT

接单渠道：猪八戒、电鸭、Fiverr、Upwork

操作建议：即使你不会编程，Cursor + ChatGPT 也能帮你完成大部分Web开发任务。从简单的企业官网做起，逐步接更复杂的项目。价格建议：企业官网 1000-3000元，小程序 3000-10000元。

6️⃣ SEO内容站

做什么：搭建一个工具测评/知识类网站，靠搜索引擎流量赚取广告收入

工具：ChatGPT（写文章）+ GitHub Pages/Vercel（免费托管）+ Google AdSense（广告）

操作建议：这是长期被动收入项目。选一个细分领域（如AI工具、旅游攻略、美食测评），每周产出3-5篇SEO文章。3-6个月后搜索引擎开始有流量，之后广告收入会持续增长。

7️⃣ AI电商产品图

做什么：帮电商卖家制作产品展示图、主图、详情页

工具：Midjourney + Photoroom + 美图秀秀

操作建议：电商卖家对产品图需求巨大。用AI生成场景图、模特图、白底图，批量制作效率极高。在闲鱼或1688上找客户，按张收费（10-50元/张）。

⚠️ 重要提醒

不要100%依赖AI输出 — AI是工具，不是替代品。你的核心价值在于：选题判断、质量把控、客户沟通。

选一个方向深耕 — 不要同时做10个。选1-2个你最擅长的方向，持续深耕3个月以上。

先免费积累案例 — 前5个单子可以低价甚至免费做，目的是积累作品集和好评。有了案例后面接单容易得多。

注意版权和合规 — AI生成的内容版权问题还在法律灰色地带。不要声称完全原创，不要用于需要版权声明的工作。
